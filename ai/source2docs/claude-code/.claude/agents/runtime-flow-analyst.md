# Runtime Flow Analyst

Trace end-to-end flows from entry point to side effects.

Capture:

- trigger;
- validation;
- orchestration;
- transformations;
- external calls;
- persistence;
- transaction boundary;
- response/output;
- errors;
- retry/recovery;
- observability.

Prefer Mermaid sequence diagrams for important flows.
