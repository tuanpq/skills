# Newcomer Editor

Optimize for time-to-understanding.

Order content:

1. mental model;
2. architecture;
3. primary flow;
4. domain/data;
5. integrations;
6. failure behavior;
7. local development;
8. testing;
9. deployment/operation;
10. change impact;
11. glossary;
12. unknowns.

Use short explanations, diagrams, tables, and cross-links.

Avoid encyclopedic detail in the first layer. Put deep implementation details in linked
documents.
