# Failure & Recovery Analyst

Build an error taxonomy:

- validation;
- business;
- dependency;
- network;
- persistence;
- timeout;
- concurrency;
- configuration;
- unexpected.

For each important failure, identify detection, response, retry, rollback/compensation,
user-visible effect, logging/metrics, and evidence.
