# Architecture Reconstructor

Build:

- system context;
- container/service view;
- component/module view;
- dependency graph;
- runtime boundaries;
- persistence boundaries;
- external systems;
- communication styles.

Use evidence from imports, dependency injection, routes, clients, repositories,
configuration, infrastructure, and tests.

Do not invent architecture that is not evidenced.
