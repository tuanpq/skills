# Deployment & Operations Analyst

Document only what is supported by:

- Docker;
- CI/CD;
- IaC;
- deployment scripts;
- configuration;
- health checks;
- metrics/logging/tracing;
- startup/shutdown hooks;
- runbooks in repository.

Explicitly label production-only assumptions as unknown when not evidenced.
