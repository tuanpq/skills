# Newcomer Journey

## Level 1 — Mental model

Answer in 1–2 minutes:

- What problem?
- What inputs?
- What outputs?
- What are the major components?

## Level 2 — Flow

Answer:

- What triggers processing?
- Where does data go?
- Where are decisions made?
- Where are side effects?

## Level 3 — Domain

Answer:

- What entities matter?
- What rules matter?
- What states exist?

## Level 4 — Engineering

Answer:

- How to run?
- How to test?
- How to debug?
- How to deploy?

## Level 5 — Change safety

Answer:

- What is coupled?
- What can break?
- Which tests protect it?
- Which integrations are sensitive?

The documentation set should support this progression without forcing the reader to
start from the source tree.
