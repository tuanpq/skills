# Japanese Technical Documentation Standard

## Writing principles

- Concise.
- Explicit.
- Consistent terminology.
- Separate fact and interpretation.
- State assumptions.
- Prefer tables for catalogs and matrices.
- Prefer diagrams for topology and flow.
- Keep source identifiers in code formatting.

## Recommended Japanese vocabulary

| English | Japanese |
|---|---|
| Purpose | 目的 |
| Scope | 対象範囲 |
| Assumption | 前提 |
| Responsibility | 責務 |
| Constraint | 制約 |
| Dependency | 依存関係 |
| Flow | 処理フロー |
| Exception | 例外 |
| Recovery | リカバリ |
| Configuration | 設定 |
| Operation | 運用 |
| Traceability | 追跡可能性 |
| Unknown | 未確認事項 |

## Quality characteristics

A strong document is:

- readable by a newcomer;
- traceable to evidence;
- consistent with implementation;
- navigable;
- visually explanatory;
- explicit about uncertainty;
- useful during change and incident investigation.
